# ADR-0005: 弦セクションは固定アンカーと編成バリアントから生成する

- 状態: 採用
- 対象: 弦楽器テンプレート

## 背景

過去の弦セクション配置では、セクションごとの人数や角度を動的に組み立てる方式を検討した。履歴資料では、列が蛇行する、プルトが詰まりすぎる、三角形状に寄りすぎるなど、演奏者が読む配置として不安定な結果になったことが記録されている。演奏会ごとの任意人数をその場で最適化することより、再現性のある標準配置を優先する必要があった。

## 決定

`src/core/stringLayoutAnchors.ts`に編成別の固定アンカーを置き、`src/core/stringLayout12.ts`で8／10／12／14／16型と4バリアントを選択して通常の椅子・スツール・譜面台オブジェクトを生成する。指揮者原点、画面上を舞台奥（Y負方向）とする座標前提、全体間隔等の限られた補正値は明示的な契約として扱う。人数を任意入力する一般最適化エンジンにはしない。

## 理由と結果

- 形状と間隔の再現性を保ち、実演者が読める標準配置を維持できる。
- 生成結果をmmだけの純粋関数としてテストできる。
- UIのライブプレビューと確定結果を同じ計算で共有できる。
- 任意編成や奇数人数を扱う要求が出た場合は、固定テンプレートへ暗黙に追加せず、別の仕様・受入・配置アルゴリズムとして設計する。

## 注意

ファイル名に`12`が残っているのは歴史的な命名であり、現行仕様が12型だけという意味ではない。旧仕様書・旧HANDOFFの12型限定記述は、現行コードと照合してから読む。

## 根拠
