# 1. 背景・目的

現行の2D編集画面は、キーボードで到達できる操作が「編集コマンド（Ctrl系）・位置の微調整（矢印）・キャンセル（Escape）」の3種に限られる。
モード切替、プリセットの選択、回転、表示範囲の指定はすべてツールバーまたはプロパティパネルのボタン専用であり、キャンバスとパネルの間をマウスで往復する時間が作業時間の大半を占める。

本仕様は、**既存の機能・データモデル・配置計算を一切変更せずに、同じ操作へ到達する経路を短くする**ことだけを目的とする。

## 1.1 最重要原則

- 配置・寸法の正本はmmであり、本仕様の変更でmm値の計算経路に触れない。
- `SceneObject`・`Project`・`schemaVersion`・`deserializeProject` を変更しない。
- 既存のAction名・reducerの挙動・Undo履歴の単位を変更しない。新規Actionは原則追加しない（追加が必要な場合は6章の条件に従う）。
- 既存の操作手段（ツールバーのボタン、パネルのボタン、ドラッグ）を削除・置換しない。**すべて追加**とする。
- キー入力の意味付けは `src/core/keyboardShortcuts.ts` の純粋関数に集約し、Reactコンポーネントへ `event.key` の判定を書かない。
- 追加したキー割当は `src/core/keyboardShortcuts.test.ts` に単体テストを持つ。
- 精密配置ツールとして、慣性・バウンド・位置の補間を追加しない。ポインタ座標と要素位置は常に1:1で同期させる。
- タッチのみの環境（iPad）で到達できなくなる機能を作らない。キーボード専用の機能を追加する場合、同じ操作へ到達するボタンまたはメニュー項目が既に存在することを確認する。

# 2. 適用範囲

## 2.1 本仕様に含むもの

- モード切替・回転・ズーム・プリセット呼び出しのキーボードショートカット（Phase A）
- パネル操作後のキャンバスへのフォーカス復帰（Phase A）
- キーボードによる選択の巡回（Phase A）
- 中ボタン／スペースキーによるパン、トラックパッド操作の区別、修飾キー併用のドラッグ複製・スナップ一時無効（Phase B）
- コマンドパレット、ショートカット一覧、コンテキストメニューの拡張（Phase C）

## 2.2 本仕様に含まないもの

- 配置計算・スナップ計算・弦楽器テンプレ・円弧配置のアルゴリズム変更
- シンボル・プリセット寸法・ラベル仕様の変更
- 保存形式（JSON）の変更、`schemaVersion` の更新
- PNG／PDF出力の内容変更
- 3Dビュー（`Viewer3D.tsx`）内のキー操作の変更（既存のWASD／矢印はそのまま）
- 配色・角丸・書体などの見た目の変更

## 2.3 現状の実装（変更前の事実）

| 操作 | 現在の手段 | 実装箇所 |
|---|---|---|
| 編集コマンド | Ctrl/Cmd+Z・Y・Shift+Z・C・X・V・Shift+V・D・A・G・Shift+G、Delete/Backspace | `src/core/keyboardShortcuts.ts:39` |
| 位置の微調整 | 矢印=10mm、Shift+矢印=100mm | `src/App.tsx:613` |
| キャンセル | Escape | `src/App.tsx:595` |
| ズーム | ホイール（無条件・1.15倍）、ツールバー±（1.25倍）、全体表示ボタン | `CanvasStage.tsx:273`、`Toolbar.tsx:163` |
| パン | 空白部分の左ドラッグ、2本指ピンチ | `CanvasStage.tsx:711` |

# 3. Phase A — キーボードショートカットの拡張

## 3.1 キー割当表

すべて**修飾キーなしの単キー**（一部Shift併用）とする。大文字小文字は区別しない（`event.key.toLowerCase()` で判定）。

### FR-UX-501 モード切替

| キー | ToolMode | 表示名 |
|---|---|---|
| `V` | `select` | 選択・移動 |
| `B` | `selectRect` | 範囲選択 |
| `M` | `measure` | 距離を測る |
| `W` | `traceWall` | 壁トレース |
| `K` | `calibrate` | 縮尺合わせ |
| `P` | `aimPoint` | 指定点へ向ける |

### FR-UX-502 注釈モード切替

| キー | ToolMode | 表示名 |
|---|---|---|
| `T` | `annotationText` | 文字注釈 |
| `L` | `annotationLine` | 線注釈 |
| `A` | `annotationArrow` | 矢印注釈 |
| `R` | `annotationRect` | 矩形注釈 |
| `O` | `annotationCircle` | 円注釈 |
| `N` | `annotationDimension` | 寸法線 |

モード切替キーは、ツールバーの `setMode()`（`Toolbar.tsx:153`）と**同じトグル挙動**とする。すなわち現在のモードと同じキーを押した場合は `select` へ戻る。
`traceWall` 以外へ切り替える際は壁トレースの下書き（`wallDraft`）を破棄する。これも既存の `setMode()` と同じ扱いにする。
`verifyCalibration`（縮尺確認）はキーを割り当てない。未校正時に無効という条件付きのモードであり、誤爆時の説明コストに見合わないため。

### FR-UX-503 回転

| キー | 動作 | 使用Action |
|---|---|---|
| `]` | +15度 | `ROTATE_SELECTED_DELTA` |
| `[` | -15度 | `ROTATE_SELECTED_DELTA` |
| `Shift+]` | +5度 | `ROTATE_SELECTED_DELTA` |
| `Shift+[` | -5度 | `ROTATE_SELECTED_DELTA` |

有効条件は `PropertyPanel` の `orientationEditEnabled` と同一とする。無効な状態（選択なし、ロック中、背景固定など）ではキーを無視し、通知は出さない。

### FR-UX-504 表示範囲

| キー | 動作 | 使用関数 |
|---|---|---|
| `F` | 図面全体を表示 | `fitViewToProject`（`transform.ts:237`） |
| `Shift+F` | 選択物にフィット | 新規（3.4参照） |
| `=` または `+` | 拡大（1.25倍） | `zoomAt`（`transform.ts:206`） |
| `-` | 縮小（1/1.25倍） | `zoomAt` |

`Ctrl+0` / `Ctrl++` / `Ctrl+-` は**採用しない**。ブラウザ既定のページズームと衝突し、環境によっては `preventDefault()` で抑止できないため。

拡大・縮小の基準点はキャンバスの中央とする（ツールバーの `zoomBy()` と同一）。ズーム倍率の上下限は既存どおり `0.005`〜`2`。

### FR-UX-505 直前プリセットの再呼び出し

| キー | 動作 |
|---|---|
| `Q` | 最後に配置したプリセットを配置待機状態にする |

- 参照元は `state.libraryPreferences.recentPresetIds[0]`（`core/library.ts:9`）。
- 使用Actionは `SET_PENDING_PRESET`。
- 履歴が空、または該当プリセットが現在のプリセット一覧に存在しない場合はキーを無視する。
- 未校正時・配置先レイヤーが非表示／ロック時は、ライブラリのカードをクリックしたときと同じ通知文を出す。通知文の判定は既存の `canPlaceObjects()` を使い、文言を新規に作らない。

### FR-UX-506 お気に入りプリセットの数字キー

| キー | 動作 |
|---|---|
| `1`〜`9` | `state.libraryPreferences.favoritePresetIds` の1〜9番目を配置待機状態にする |

- 該当位置にお気に入りが無い場合はキーを無視する。
- 無効条件・通知はFR-UX-505と同一。
- ライブラリパネルのお気に入りカードに `1`〜`9` の番号バッジを表示する。これが無いと割当を知る手段がないため、バッジの表示は本要件に含む。

### FR-UX-507 選択の巡回

| キー | 動作 |
|---|---|
| `Tab` | 次のオブジェクトを単独選択する |
| `Shift+Tab` | 前のオブジェクトを単独選択する |

- **キャンバスにフォーカスがあるときのみ**動作する。他の場所ではブラウザ既定のフォーカス移動を妨げない。
- 巡回対象は「表示中かつロックされていないレイヤーに属するオブジェクト」を `zIndex` 昇順、同値なら配列順で並べたもの。
- 末尾から `Tab` を押すと先頭へ戻る（循環）。
- 選択が空のときは先頭（`Shift+Tab` では末尾）を選ぶ。
- 選択したオブジェクトが表示範囲外にある場合でも、ビューは自動で動かさない（意図しないパンを避けるため）。ユーザーは `Shift+F` で寄せられる。

### FR-UX-508 キャンバスへのフォーカス復帰

パネル上のボタンで**選択物に作用する操作**を実行した直後、キャンバスへフォーカスを戻す。

対象:

- プロパティパネルの回転（±5／±15度）、指揮台へ向ける、整列・分配、左右対称複製
- ツールバーのモード切替ボタン、Undo／Redoボタン、ズーム・全体表示ボタン

対象外（フォーカスを移さない）:

- ファイル操作（新規・開く・保存・出力）
- パネルの開閉、表示設定、レイヤーパネル、ライブラリの検索欄
- 各種ダイアログ内のボタン

理由: 現状 `blocksCanvasShortcut()`（`keyboardShortcuts.ts:96`）は、フォーカスがボタン等にある間 `delete` と矢印キーを無効化する。この判定自体は誤操作防止として妥当なので変更せず、フォーカスの側を戻すことで「ボタンを押した直後に矢印で寄せる」を成立させる。

実装方式:

- `App.tsx` がキャンバスへのフォーカス関数を保持し、`Toolbar` / `PropertyPanel` へ `onFocusCanvas?: () => void` として渡す。
- `CanvasStage` は既存の `svgRef`（`CanvasStage.tsx:217`）を使い、マウント時に App へフォーカス関数を登録する。
- `document.querySelector` によるDOM直接参照は使わない。
- フォーカス移動は `requestAnimationFrame` 内で行う（`App.tsx:267` に既存の同じ書き方がある）。

## 3.2 入力の除外条件

以下の場合、Phase Aで追加するすべての単キーショートカットを**無効**とする。

1. `blocksCanvasShortcut()` がテキスト編集中と判定したとき（`INPUT` / `TEXTAREA` / `SELECT` / contenteditable / `role="textbox"`）。既存判定をそのまま使う。
2. 日本語入力（IME）の変換中。`KeyboardEvent.isComposing === true` または `keyCode === 229` のとき。
   - `KeyboardShortcutInput` へ `isComposing?: boolean` を追加し、`getKeyboardShortcut()` の先頭で `null` を返す。既存の呼び出し側が壊れないよう省略可能とする。
3. 確定前プレビューのセッション中（`chairArc` / `stringTemplate` / `chairLine` / `riserGroup` / `lineArrangement` が非nullのとき）。現行の `App.tsx:560` 以降と同じ扱いで、`escape` と編集コマンドのみ通す。
4. ダイアログ表示中（`exportOpen` / `gridSourceId` / `templateSaveOpen` / 校正ダイアログ）。
5. 3Dビュー表示中（`viewer3dOpen`）。

`Tab` / `Shift+Tab`（FR-UX-507）は上記に加えて「キャンバスにフォーカスがある」ことを条件とする。

## 3.3 既存挙動との干渉

| 干渉先 | 内容 | 判断 |
|---|---|---|
| Shiftキーのkeyup | `App.tsx:648` で、Shiftを離すと配置待機（`pendingPresetId`）を解除する | `Shift+F` / `Shift+[` / `Shift+]` を使うと配置待機が解除される。配置待機中に回転・フィットを行う場面は無いため、既存ロジックを変更せず仕様として許容する |
| 配置待機中の単キー | プリセット選択中に `V` などを押すとモードが変わる | `SET_MODE` は `pendingPresetId` を `null` にする既存挙動（`appState.ts:795`）に従う。配置待機の解除は妥当な結果として許容する |
| `A` キー | 注釈矢印モード（FR-UX-502）と `Ctrl+A` 全選択 | 修飾キーの有無で分岐済み。衝突しない |
| `V` キー | 選択モードと `Ctrl+V` 貼り付け | 同上 |
| ブラウザ既定 | `Tab` のフォーカス移動 | キャンバスにフォーカスがあるときのみ奪う。`Escape` でキャンバスの選択を解除した後は通常どおりパネルへ移動できる |

## 3.4 新規に必要な純粋関数

| 関数 | 配置先 | 内容 |
|---|---|---|
| `fitViewToObjects(objects, ids, viewportWidth, viewportHeight, marginPx?)` | `src/core/transform.ts` | 選択物の外接矩形に収まる `ViewState` を返す。既存 `fitViewToProject` と `selectionBoundsMm`（`layout.ts:50`）を組み合わせる。対象が0個のときは `null` を返し、呼び出し側は何もしない |
| `nextSelectionId(objects, layers, currentId, direction)` | `src/core/layout.ts` | FR-UX-507の巡回順を返す。純粋関数とし、循環・空選択・非表示レイヤー除外をここで扱う |
| `favoritePresetIdForDigit(preferences, digit)` | `src/core/library.ts` | `1`〜`9` に対応するプリセットIDまたは `null` を返す |

`getKeyboardShortcut()` の戻り値型 `KeyboardShortcut` へ、上記に対応する値を追加する（例: `"modeSelect"` / `"rotateCw"` / `"zoomFit"` / `"repeatLastPreset"` / `"favoritePreset1"`…）。
数字キーは `"favoritePreset"` 1種とし、押された数字を別の戻り値として返す設計にしてもよい。その場合は戻り値を `{ shortcut, digit }` 形式へ変えず、`getFavoritePresetDigit(input): number | null` を別関数として追加する（既存の戻り値型を壊さないため）。

# 4. Phase B — ポインタ操作の拡張

## 4.1 FR-UX-511 中ボタンドラッグでパン

- `handlePointerDown`（`CanvasStage.tsx:526`）冒頭の `if (e.button !== 0) return;` を、中ボタン（`e.button === 1`）ならパンを開始する分岐へ変更する。
- 左ボタンの既存挙動（選択・移動・回転・注釈作成・各プレビュー操作）は一切変更しない。
- 中ボタンのドラッグ中は選択状態を変更しない（現行の空白左ドラッグは `SELECT id:null` を伴うが、中ボタンでは選択を保持する）。
- 中ボタンの既定動作（オートスクロール）を `preventDefault()` で抑止する。

## 4.2 FR-UX-512 スペースキー押下中のパン

- スペース押下中はカーソルを `grab`、ドラッグ中は `grabbing` にする。
- スペースを押している間、左ドラッグは常にパンとして扱い、オブジェクトの選択・移動を開始しない。
- スペースのkeydownは、テキスト編集中とボタンにフォーカスがある場合（スペースはボタンの実行キー）には反応しない。
- スペースを押したままキャンバス外へフォーカスが移った場合に備え、`blur` と `pointercancel` で一時パン状態を解除する。

## 4.3 FR-UX-513 トラックパッド操作の区別

- 端末ローカル設定「トラックパッドとして扱う」を追加する。既定はOFF（現行どおりホイール＝ズーム）。
- 保存先はプロジェクトJSONではなく端末ローカル（`library-preferences.v1` と同じ保存経路を使うか、同種の別キーを作る）。プロジェクトの保存内容を変えないこと。
- ON時の挙動: `e.ctrlKey === true`（ピンチジェスチャーがこのフラグで届く）のときズーム、それ以外は `deltaX` / `deltaY` に応じたパン。
- 設定の場所はツールバーの「表示設定」ポップオーバー内とする。

## 4.4 FR-UX-514 Alt+ドラッグで複製移動

- 左ドラッグ開始時に `altKey` が真で、対象がオブジェクトのとき、選択物の複製を作ってから移動を開始する。
- 複製の生成は既存の複製コマンド（`duplicate` / `editCommands.ts`）の生成規則を再利用し、ID採番・レイヤー・zIndexの規則を新規に作らない。
- ドラッグ終了時に**1回のcommit**で履歴へ入れる。ドラッグ中に履歴を積まない（既存のmoveと同じくpreview→commit方式）。
- ドラッグ開始前にAltを離した場合は通常の移動として扱う。ドラッグ中のAltの状態変化は無視する（開始時点で確定）。

## 4.5 FR-UX-515 スナップの一時無効

- ドラッグ中に修飾キーを押している間、`snapPoint()` を通さず生の座標を使う。
- 使用する修飾キーは `Ctrl`（macOSでは `Cmd`）とする。Altは FR-UX-514 に割り当てるため使わない。
- スナップが無効になっている間は、スナップガイド線を表示しない（誤解を避けるため）。
- ステータスバーに一時無効中である旨を表示する。

## 4.6 受入条件（Phase B）

| ID | 条件 |
|---|---|
| AC-PTR-001 | オブジェクトが密集した場所でも、中ボタンドラッグでパンでき、選択状態が変わらない |
| AC-PTR-002 | スペース押下中の左ドラッグがパンになり、離すと通常の選択・移動へ戻る。スペースを押したままフォーカスを外しても状態が残らない |
| AC-PTR-003 | 「トラックパッドとして扱う」ON時、2本指スクロールでパン、ピンチでズームになる。OFF時は現行どおりホイールでズームする |
| AC-PTR-004 | Alt+ドラッグで複製が作られ、ドロップ後のUndo1回で複製前へ戻る |
| AC-PTR-005 | Ctrl/Cmd押下中のドラッグでスナップが効かず、ガイド線も出ない。離すとスナップが戻る |
| AC-PTR-006 | 追加したポインタ操作のいずれにも、慣性・バウンド・位置の補間が入っていない |
| AC-PTR-007 | iPad Safariでの既存のタッチ操作（1本指ドラッグ、2本指ピンチ・パン）が変わっていない |

# 5. Phase C — 発見可能性と検索

## 5.1 FR-UX-516 ショートカット一覧

- `?`（`Shift+/`）で一覧ダイアログを開く。`Escape` で閉じる。
- 一覧の元データは `src/core/keyboardShortcuts.ts` にテーブルとして持ち、割当の実装とドキュメントが二重管理にならないようにする。
- ツールバーのモード切替ボタンの `title` 属性、および編集メニューの各項目へ対応するキーを併記する。
- macOSでは `Ctrl` を `⌘` として表示する。判定は既存の `metaKey` の扱いに合わせる。

## 5.2 FR-UX-517 コマンドパレット

- `Ctrl/Cmd+K` で開く。テキスト入力欄にフォーカスがあるときも開いてよい（修飾キー付きのため衝突しない）。
- 検索対象: プリセット、ユーザーテンプレート、一括配置ダイアログの起動、モード切替、レイヤーの切替。
- 検索の正規化・絞り込みは `normalizeLibraryQuery()` / `filterLibraryPresets()`（`core/library.ts`）を再利用し、新しい検索規則を作らない。
- 上下キーで候補移動、`Enter` で実行、`Escape` で閉じる。フォーカストラップと、閉じたときの呼び出し元へのフォーカス復帰を実装する。
- プリセットを選んだ場合の結果は「配置待機状態にする」であり、その場で配置しない（クリック位置が決まらないため）。

## 5.3 FR-UX-518 コンテキストメニューの拡張

- 現行の `ObjectContextMenu` は編集コマンドのみ。ここへ「±15度回転」「指揮台へ向ける」「整列・分配」「一括配置の起動」を追加する。
- タッチ環境ではショートカットが使えないため、Phase A で追加した操作のうちタッチから到達できないものは、このメニューで到達可能にする。
- 選択状態によって無効な項目は、`disabled` にしたうえで理由を表示する（「指揮台が図面にありません」など既存の文言を再利用）。

## 5.4 受入条件（Phase C）

| ID | 条件 |
|---|---|
| AC-DSC-001 | `?` で一覧が開き、Phase A・Bで追加した全割当が漏れなく載っている |
| AC-DSC-002 | 一覧の内容が実装のテーブルから生成されており、割当を追加したときに一覧へ自動で反映される |
| AC-DSC-003 | `Ctrl/Cmd+K` で開くパレットから、プリセット配置待機・モード切替・一括配置の起動ができる |
| AC-DSC-004 | パレットを閉じると、開く前にフォーカスしていた要素へフォーカスが戻る |
| AC-DSC-005 | iPad Safariで、コンテキストメニューから回転・向き揃え・一括配置へ到達できる |

# 7. 用語

| 用語 | 意味 |
|---|---|
| mm正本 | 位置・寸法の正本をmmで持つ設計。画面pxは表示のたびに導出する |
| 配置待機 | プリセットを選んだが、まだキャンバスをクリックしていない状態（`pendingPresetId`） |
| 確定前プレビュー | 円弧配置・弦楽器テンプレなどの、`project.objects` へ書き込む前の一時表示 |
| commit | `commitProject()` を通してUndo履歴へ1段積むこと |
